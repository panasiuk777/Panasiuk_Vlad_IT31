Практична робота 6
Варіант 3 — Кінотеатр
Завдання 1 — UPDATE у фактовій таблиці

У таблиці screenings для запису id = 1 ціну квитка змінено з 250 до 270.

Завдання 2 — UPDATE у таблиці-вимірі

Для залу id = 1 місткість змінено з 100 до 110. UPDATE доречний, тому що місткість є змінною характеристикою існуючого залу, і немає потреби видаляти старий запис та створювати новий.

Завдання 3 — DELETE одного рядка

До видалення у таблиці screenings було 10 рядків. Видалено запис id = 10. Після видалення залишилося 9 рядків, тому було видалено рівно один запис.

Завдання 4 — ON DELETE

Для зв'язку screenings.movie_id → movies.id встановлено ON DELETE RESTRICT.

Прогноз: видалення фільму, на який посилаються записи screenings, буде відхилено.

Фільм id = 1 використовувався у показах id = 1 та id = 7.

Фактичний результат:

FOREIGN KEY constraint failed


Прогноз підтвердився: SQLite не дозволила видалити фільм, оскільки на нього існують посилання у таблиці screenings.

Висновок

UPDATE дозволяє змінювати характеристики існуючих записів, DELETE видаляє конкретні записи за умовою, а ON DELETE RESTRICT захищає пов'язані дані від видалення, якщо на них існують зовнішні ключі.
