id — INTEGER PRIMARY KEY — використовується для унікального номера кожного фільму.
title — TEXT — назва фільму складається з текстових символів.
genre — TEXT — жанр також записується текстом, наприклад «драма» або «комедія».
duration_min — INTEGER — тривалість фільму вказується цілим числом хвилин.
year — INTEGER — рік виходу фільму є цілим числом.
age_rating — INTEGER — віковий рейтинг задається числом, наприклад 0, 12 або 16.

У SQLite для кожного поля обрано відповідну type affinity. Для назв і жанрів використовується TEXT, а для числових значень — INTEGER. Це відповідає характеру даних і дозволяє правильно з ними працювати.
