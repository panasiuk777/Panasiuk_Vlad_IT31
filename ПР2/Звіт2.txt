1. Чому запит WHERE price = NULL завжди повертає порожній результат? Що потрібно написати замість цього?

NULL означає відсутність або невідомість значення. Порівняння через = NULL не дає результату TRUE, тому WHERE не вибирає такі рядки. Замість цього потрібно використовувати IS NULL, наприклад:
SELECT *
FROM movies
WHERE genre IS NULL;
2. Чим WHERE відрізняється від HAVING?

WHERE фільтрує окремі рядки таблиці до групування. HAVING фільтрує вже сформовані групи після GROUP BY.
3. У якому випадку варто уникати SELECT * і чому?

SELECT * варто уникати, коли потрібні тільки певні стовпці. Краще явно вказувати потрібні стовпці, тому що запит стає зрозумілішим, повертає менше зайвих даних і не залежить від появи нових стовпців у таблиці.
